# Bot project entry instructions

Before ecosystem feature work, read `../isdalog/docs/PRODUCT_ROADMAP.md` and `../isdalog/docs/PROJECT_STATE.md`. These are the canonical cross-project plan and resumption record. If opening this repository alone without those files, recover the plan from the sibling checkout or ask for its location rather than inventing a competing roadmap.

Follow the latest user instruction, preserve existing changes, and inspect current CommonJS bot/services before editing. Coordinate authentication, ownership, validation, retry identity and response contracts with the Laravel application. Keep cloud/edge fallback and recoverable conversational behavior intact unless the authorized slice specifically changes them.

Update the canonical state after implementation with roadmap ID, evidence, limitations and next step. Do not claim AI species suggestions establish legal compliance or that an unconfirmed submission/payment succeeded. Do not expose credentials, account details or handover codes in logs.
